Access token lifetime5–15 minutes

Refresh tokenRotate on use; absolute lifetime (e.g. 8–24 h for web)
PKCERequired, S256 only
state / nonce≥ 128 bits random, per request and per leg, single use
JWT algorithmPin to RS256 (or ES256); reject none and HMAC with public keys
JWKS cache1–24 h; refetch once on unknown kid (rate-limited)
Clock skew allowance≤ 60 seconds

curl one-liners

# Is discovery public and correct?
curl -s https://test.partnerlink.enterprise.com/mga/sps/oauth/oauth20/metadata/PartnerLink_OIDC_Test | jq '{issuer,jwks_uri,token_endpoint,code_challenge_methods_supported}'

# Is JWKS reachable from THIS host? (egress IP matters)
curl -s -o /dev/null -w '%{http_code} %{content_type}\n' https://test.partnerlink.enterprise.com/mga/sps/oauth/oauth20/jwks/PartnerLink_OIDC_Test

# Which layer answered?
curl -sI https://test.partnerlink.enterprise.com/mga/sps/oauth/oauth20/jwks/PartnerLink_OIDC_Test | egrep -i '^(HTTP|server|location|set-cookie)'

# Exchange a code (back channel)
curl -s -X POST https://test.partnerlink.enterprise.com/mga/sps/oauth/oauth20/token \
  -d grant_type=authorization_code -d code="$CODE" -d redirect_uri="$REDIRECT" \
  -d client_id="$CID" -d client_secret="$SECRET" -d code_verifier="$VERIFIER"

# Decode a JWT part (1=header, 2=payload)
jwt() { cut -d. -f"$2" <<<"$1" | tr '_-' '/+' | awk '{l=length($0)%4; if(l==2)$0=$0"=="; else if(l==3)$0=$0"="; print}' | base64 -d 2>/dev/null | jq .; }

# PKCE pair
V=$(openssl rand -base64 48 | tr -d '=+/\n' | cut -c1-64)
C=$(printf %s "$V" | openssl dgst -sha256 -binary | openssl base64 -A | tr '+/' '-_' | tr -d '=')

# Count '?' in a redirect Location (expect 1)
curl -sI "$URL" | grep -i '^location:' | tr -cd '?' | wc -c

# Verify SaaS discovery
curl -s https://TENANT.verify.ibm.com/oidc/endpoint/default/.well-known/openid-configuration | jq .
