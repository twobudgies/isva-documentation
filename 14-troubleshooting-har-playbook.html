14 · Operational Runbook: HAR & JWT Debugging

When login breaks, work the problem in layers — edge, proxy, runtime, rule, token — using a HAR capture, a few curl commands and a JWT decoder. This page is the on-call playbook for the whole site.

1. Zero-knowledge explanation

📘 Beginner Concept — a HAR file is a flight recorder

A HAR (HTTP Archive) is a recording of everything your browser sent and received: URLs, status codes, headers, cookies, timings. Capture one and you can replay the story of a login. Read it like a detective: which was the last good response, and what was the first bad one? Every status code points at a layer: 403 + Akamai page → edge; 302 to a login page → WebSEAL ACL; 400 JSON error → OAuth runtime; token rejected by the app → validation.

How to capture a clean HAR

  1. Open DevTools → Network; tick Preserve log and Disable cache.
  2. Use a private window; start capture; perform the login; stop at the failure.
  3. Right-click → Save all as HAR with content.
  4. Sanitize before sharing: HARs contain cookies, codes and tokens. Remove Cookie, Set-Cookie, code=, id_token values (or revoke after).

2. High-level architecture — triage tree

🏗️ Architecture Deep Dive — identify the layer first
Never edit ISVA config before you know which layer answered. Response headers tell you: Server: AkamaiGHost = edge; WebSEAL-style error ids HPDIA…/pkmslogin.form = WebSEAL; JSON {"error":…} = OAuth runtime.

3. Low-level technical sequence — reading a HAR

HAR one-liners (needs jq)

# overview: status, method, url
jq -r '.log.entries[] | "\(.response.status) \(.request.method) \(.request.url | .[0:140])"' login.har

# every redirect and where it points
jq -r '.log.entries[] | select(.response.status>=300 and .response.status<400) |
  "\(.response.status) \(.request.url | .[0:80]) -> \(.response.headers[] | select(.name|ascii_downcase=="location") | .value | .[0:160])"' login.har

# Akamai blocks
jq -r '.log.entries[] | select(.response.content.text // "" | test("errors.edgesuite.net")) | .request.url' login.har

# which requests carried the ciam session cookie?
jq -r '.log.entries[] | select(.request.cookies[]?.name=="PD-S-SESSION-ID") | .request.url | .[0:100]' login.har

# double-question-mark URLs (finding #3)
jq -r '.log.entries[].request.url | select(test("\\?.*\\?"))' login.har

Decode a JWT without leaving the terminal

jwt() { cut -d. -f"$2" <<<"$1" | tr '_-' '/+' | awk '{l=length($0)%4; if(l==2)$0=$0"=="; else if(l==3)$0=$0"="; print}' | base64 -d 2>/dev/null | jq .; }
jwt "$ID_TOKEN" 1    # header: alg, kid
jwt "$ID_TOKEN" 2    # payload: iss, aud, exp, nonce, sub
date -r "$(jwt "$ID_TOKEN" 2 | jq .exp)"     # macOS expiry; Linux: date -d @EXP

4. Environment deep dive — curl verification suite

Run from the same host as partner_portal_backend (egress IP matters for Akamai). Set HOST, CID, SECRET.

#!/usr/bin/env bash
HOST=https://test.partnerlink.enterprise.com
B=$HOST/mga/sps/oauth/oauth20
CID='<partner_portal_clientid>'

echo "== 1 metadata";  curl -s -o /dev/null -w '%{http_code} %{content_type}\n' $B/metadata/PartnerLink_OIDC_Test
echo "== 2 issuer";    curl -s $B/metadata/PartnerLink_OIDC_Test | jq -r .issuer
echo "== 3 jwks";      curl -s -o /dev/null -w '%{http_code} %{content_type}\n' $B/jwks/PartnerLink_OIDC_Test
echo "== 4 kids";      curl -s $B/jwks/PartnerLink_OIDC_Test | jq -r '.keys[].kid'
echo "== 5 edge?";     curl -sI $B/jwks/PartnerLink_OIDC_Test | egrep -i '^(server|http|location)'
echo "== 6 authsvc no-PKCE (should be rejected)"
curl -sI "$HOST/mga/sps/authsvc?client=$CID&scope=openid&state=t1" | egrep -i '^(http|location)'
echo "== 7 nested ? count (expect 1)"
curl -sI "$HOST/mga/sps/authsvc?client=$CID&scope=openid&state=t1" | grep -i '^location:' | tr -cd '?' | wc -c
echo "== 8 ROPC disabled (expect unsupported_grant_type)"
curl -s -u "$CID:$SECRET" -d grant_type=password -d username=x -d password=y $B/token
echo "== 9 bad code (expect invalid_grant)"
curl -s -u "$CID:$SECRET" -d grant_type=authorization_code -d code=bogus -d redirect_uri=https://portal.example.com/cb $B/token
echo "== 10 metadata advertises S256"
curl -s $B/metadata/PartnerLink_OIDC_Test | jq .code_challenge_methods_supported

⚠️ Security Pitfall — debugging hygiene
Don't paste live codes, tokens, secrets or HARs into tickets or chat. Treat any token seen in a HAR as compromised if it was still valid. Turn runtime tracing off after use and purge trace.log.
